# 拾用 PocketKit — 设计说明

开发版 0.1.0 ｜ 包名 `cn.xianhua.pocketkit` ｜ 原生 Java + View；用户已授权按已选功能扩展，必要能力复用经核验的库或 SDK。界面默认跟随系统。

---

## 1. 主题定位

**「机床台面」**。拾用不是内容浏览应用，是随时伸手取用的一把工具。视觉母题取自精密量具与钳工工作台：冷调工作台面、刻度、游标、量爪、读数窗。

三个必须做到的事，来自任务书：
- **便携工作台** —— 打开即台面，工具像被摊在台面上，不是一叠卡片。
- **清晰好找** —— 搜索常驻首屏，分类标签平铺，任何工具两跳内可达。
- **触控易达** —— 底部导航、56dp 行高、48dp 以上触控目标，拇指区优先。

## 2. 设计令牌

### 2.1 颜色

六个命名色构成基底，**颜色只承载状态，不承载氛围**。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `paper` | `#EDF1EF` | `#0F1517` | 工作台面底色（冷雾灰绿） |
| `surface` | `#FFFFFF` | `#161E20` | 抬起的台面、行、读数窗 |
| `sunken` | `#E1E7E4` | `#0A0F11` | 凹槽：搜索槽、输入框、置顶托盘 |
| `ink` | `#182A2E` | `#E3ECEA` | 主文本（深石油色，非纯黑） |
| `inkSoft` | `#5B6E72` | `#93A7A9` | 次级说明、单位、提示 |
| `rule` | `#C7D2CF` | `#2C3A3C` | 发丝线、刻度、分隔 |

两个语义强调色，**只表示状态**：

| 令牌 | 浅色 | 深色 | 语义（唯一用途） |
|---|---|---|---|
| `petrol` | `#0E6E6B` | `#45B0A8` | 选中 / 主操作 / 刻度（当前所在处） |
| `signal` | `#B9660E` | `#E1943C` | 进行中（计时器运行、置顶建议标注） |

辅助：`danger #A63232`（错误）、`ok #2E7D4F`（成功）。

> **为什么不是米色 + 暖橙**：任务书点名要避开。量具、卡尺、切削垫板的世界是冷灰绿的金属与油石，不是暖白纸张。`#EDF1EF` 是带绿相的冷雾色，与 `#F4F1EA` 系奶油底完全不同色相。
> **为什么不是纯黑 + 荧光**：深色主题用 `#0F1517`（蓝绿黑，非 `#0B0B0B`），强调色 `#45B0A8` 是降饱和的松绿，不是荧光酸绿。

### 2.2 字体

| 角色 | 字族 | 字重 | 字号 |
|---|---|---|---|
| 读数 / 大数字 | `sans-serif-condensed` | BOLD | 26sp |
| 标题 | `sans-serif` | MEDIUM | 17sp |
| 正文 | `sans-serif` | NORMAL | 15sp |
| 分类标签 | `sans-serif` | MEDIUM | 13sp |
| 说明 / 单位 | `sans-serif` | NORMAL | 12sp |
| 机器数据（HEX、摘要、进制） | `monospace` | NORMAL | 14sp |

- **condensed 用于读数**，取量具表盘的窄体读数感；数字列因此天然对齐。
- **monospace 只出现在列对齐真正是信息的地方**（摘要、进制、HEX）。它不作为「小标签」的装饰字体。
- 中文由系统 CJK 回退渲染，字族选择实际作用于拉丁字母与数字；这一点在 `docs/README.md` 的限制里如实写明。
- 行宽：正文段落上限约 34 个汉字；读数行右对齐在固定列。
- 字号阶梯 26 / 20 / 17 / 15 / 13 / 12 sp，全部 sp，随系统字号缩放。

### 2.3 布局

```
┌───────────────────────────────┐  状态栏内边距（透明状态栏 + insets）
│ 拾用                    ☾ 深色 │  48dp 标题带，无大写眉标
│ ┌───────────────────────────┐ │
│ │ ⌕  搜索工具                │ │  凹槽搜索框 44dp
│ └───────────────────────────┘ │
│ ╔═ 置顶（建议，可取消）══════╗ │  托盘顶沿 = 刻度线
│ ║ [▤ 文本清理][◈ 摘要][▦ 取色]→║ │  横向滚动，高 68dp
│ ╚═══════════════════════════╝ │
│  文本与编码                    │  13sp petrol 分类标签
│  ▤  文本清理统计           ›  │  56dp 整行
│  ▤  Base64 编解码          ›  │
│  ▤  URL 编解码             ›  │
│  数据与摘要                    │
│  ▤  MD5 / SHA-256         ›  │
│  ▤  进制转换               ›  │
│  …                            │
├───────────────────────────────┤
│   台面      最近      设置     │  底部导航 56dp + 导航栏 insets
└───────────────────────────────┘
```

- 全部**左对齐**；唯一右对齐的是读数窗里的数值列（对齐即信息）。
- 唯一居中处：屏幕大字页与计时器圆盘的**仪表盘时刻**，本身就是量具表面。
- 工具目录是**整行清单，不是等尺寸卡片墙**。工具是被查找的，不是被浏览的。
- 工具页：标题带 → 输入区 → 主操作行 → 读数窗 / 结果区，纵向单列。

### 2.4 原则

1. 每个控件都说明它做什么；不存在需要猜的无字图标按钮。
2. 刻度母题只出现在两处：置顶托盘的上沿、专注计时圆盘的进度弧。**只在一处花力气。**
3. 颜色只编码状态。`signal` 只用于「正在运行 / 这是建议」，绝不装饰。
4. 结果一律进读数窗，右对齐数值列；错误直接说明原因与下一步，不道歉、不含糊。
5. 无账号、无广告；默认本地处理。用户已选择联网工具，必须明确标注联网、上传目的与风险。未实现项显示原因且不作为可用按钮；权限在使用时申请。

## 4. 无障碍与系统适配

- 对比度：浅色 `ink #182A2E` 于 `paper #EDF1EF` 约 13:1；`petrol` 于 `surface` 约 5.6:1，均超过 WCAG AA。
- 触控目标 ≥ 48dp；行高 56dp；按钮最小高 48dp。
- 边到边：状态栏/导航栏透明 + `WindowInsets` 内边距；键盘弹出时（API 30+ 用 `Type.ime()`，低版本用可视区域差值）把内容抬到键盘之上。
- 旋转：Activity 重建，各工具面板通过 `onSaveInstanceState` 保存输入与结果。
- 返回：工具页是独立 Activity，系统返回键直接回台面。
- 深色模式：`values-night` 主题 + 应用内三态（跟随系统 / 浅 / 深）。
