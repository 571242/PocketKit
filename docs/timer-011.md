# 计时器与番茄钟 0.11.0

倒计时与番茄钟现在把状态保存在 SharedPreferences，并用 AlarmManager 调度单次后台提醒。开始、暂停、继续、加时、停止都会同步落盘和排撤闹钟；停止会清掉通知。番茄的专注、休息阶段仍需用户明确开始，不会自动循环。

运行中的时长以 elapsedRealtime 单调时钟计算；用 Settings.Global.BOOT_COUNT 判断重启，不会因用户改时间或网络校时误判。设备重启后正在运行的计时作废，暂停状态可保留；读取恢复状态不会补发历史提醒。前台与广播接收器共用已通知状态，防止重复提醒，两种模式的通知入口互不覆盖。

Manifest 已接入非导出的 TimerAlarmReceiver 和 SCHEDULE_EXACT_ALARM。Android 12 及以上可由用户授权精确闹钟，未授权时回退到近似提醒；Android 13 及以上需要通知权限。没有永久后台线程，也没有为了计时启动前台服务。

## 验证与边界

TimerStateTest 覆盖到期、恢复、取消、暂停、重启、模式隔离和通知去重。具体本次执行结果见发布验证记录。

未连接 Android 设备，通知、震动、锁屏和厂商省电策略未做真机验证。近似闹钟延迟由系统决定，不承诺延迟上限；强行停止应用、关闭通知、厂商后台限制仍可能阻止提醒。重启不自动续算正在运行的计时。纪念日提醒、循环番茄和历史统计不在本次范围。
