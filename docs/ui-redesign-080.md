# 0.8.0 界面设计

## 方向

原生 Android 的个人工具抽屉，而不是资讯首页。主任务是快速找工具、恢复最近工作。保留现有置顶和最近记录，不新增账号、网络字体或图片依赖。

## 视觉系统

- 雾白 #F3F6FB：页面底色。
- 纯白 #FFFFFF：输入区和工具卡。
- 墨蓝 #172D4D：正文和标题。
- 钴蓝 #2264DC：交互主色。
- 湖蓝 #087F92：声音与媒体类别。
- 石蓝 #61718A：辅助文字。

字体采用设备原生 sans-serif，标题 sans-serif-medium；正文 15–16sp，卡片标题 16sp，首页标题 30sp。中文优先，不下载字体。不同类别使用低饱和背景和线性图标，深色模式保留相同层级。

## 布局

所有内容左对齐。首页把可操作的声音入口作为唯一大色块，工具卡保留安静的白底。底部四入口固定可达；搜索跨越分类，全部页可选类别。

## 设计复核

不采用通用营销头图、渐变背景、大数字统计或装饰编号。声音入口波形只表达实际影音用途；工具图标用本地矢量绘制，不依赖 emoji 在不同手机的表现。分类从原模块导向调整为用途导向，避免“抢票助手在传感器”“视频在文档”这类错位。

## 验证边界

编译和离线断言只证明代码与分类规则，不替代手机屏幕、触控和字体缩放验收。
