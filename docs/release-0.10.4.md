# PocketKit 0.10.4

版本：0.10.4（versionCode 28）。使用与 0.10.3 相同的应用 ID 和签名，覆盖安装即可；不要为更新而卸载或清数据。APK 更新仍只走 GitHub 仓库，不新增更新入口，不改服务器的 APK 更新配置或用户订阅/节点。

## 本次修复

- 分流默认规则由少量常用域名改为完整、经校验的随包快照（147,559 条；2,258,010 字节）。首次安装或无法连接规则服务器时也有完整的国内域名、中国 IP 与明确代理规则。云端与有效本地快照哈希一致时不重复下载。
- 规则清单和文件优先通过物理网络下载，避免更新依赖可能已经异常的 VPN。连接重置、超时或 TLS 连接错误时，仅通过当前网络再尝试一次；两次都失败明确显示失败并保留本地规则。HTTPS、同源/同路径跳转、大小、SHA-256、严格 JSON 格式与原生内核校验仍保留，没有降级 TLS。
- 代理 DNS 改为 TCP，不要求所选节点支持 UDP DNS 转发。代理模式的 DNS 改为只返回 IPv4，规避已复现的东京出口 IPv6 TLS 断流；直连模式保留 IPv6 行为。
- 规则模式在明确域名策略之后、中国 IP 兜底之前解析仅有域名的连接，让 CN CIDR 对混合代理入口的域名请求也生效；不抢在明确代理域名之前做直连 DNS。
- 页面、快捷面板、常驻通知及 VPN 会话改为显示实际规则/全局/直连模式，不再把全局显示为“规则代理”。
- 恢复“其他打开方式”中的“拾用·定位文件位置”。仍进入原文件的真实父目录，复用现有目录导航，不复制文件假装定位，不新增权限申请。支持带 MIME 及不带 MIME 的文件 URI；已打开窗口再收到文件时也处理请求。

## 验证边界

没有连接 Android 真机。未验证手机 TUN、ROM 的“其他打开方式”列表、覆盖安装和浏览器完整通过 Cloudflare 验证。HTTP 403 challenge 代表已到达网站，并不代表页面内容正常加载；没有将其记为完整浏览成功。

代理模式当前采用 IPv4 兼容策略，因此仅有 IPv6 地址的域名可能无法访问；不改变 VPN 的 IPv6 接管范围，也不把 IPv6 流量绕到隧道外。没有新增核心更新、额外设置或网站特判。
