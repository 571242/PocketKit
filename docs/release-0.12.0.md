# 拾用 0.12.0：无痕浏览与加密冻结

入口：全部 → 网络工具 → 无痕浏览。浏览器使用系统 Android WebView，不附带 Chromium/Gecko 内核；此工具需要 Android 9 及以上，建议更新系统 WebView。

## 使用方式

- “开始新无痕会话”创建独立网页数据目录，不与阅读器等工具共享 Cookie。
- 地址栏支持网址和 Bing 搜索；底部提供后退、前进、刷新、收藏、冻结与退出。
- “收藏”保存标题和完整网址。收藏保存在应用私有目录，**不加密**；保存前可编辑网址并去除敏感参数。
- “冻结”会停止浏览并退出，在冻结库中保存加密副本。稍后点击该窗口解冻；长按可删除。退出时也可选择“冻结并退出”。
- “清除并退出”只丢弃当前活动会话；已成功保存的冻结副本和收藏保留。

## 冻结保留什么

冻结的是**整个隔离会话**的站点数据，不限当前网站：包括 Cookie 数据库（含 HttpOnly Cookie 的属性）、Local Storage、IndexedDB 等；另外保存当前页面的标题、网址、阅读位置与同源 sessionStorage。页面临时缓存和引擎锁不归档。会话中的多个网站可能都有登录凭据，请按敏感数据看待。

冻结资料使用 AndroidKeyStore 的不可导出 AES 密钥加密。密钥不写入档案；归档路径名称也在加密载荷里，冻结库不上传、不参加备份。活动页面运行时，数据仍位于应用私有明文工作目录，不能宣称取证级无痕。

归档前先结束独立浏览进程，以操作系统文件锁确认 WebView 不再写目录，再由主进程加密。解冻在认证成功后才启用还原的目录。原副本保留到新冻结成功；保存失败保留待冻结会话，可重试或明确清除。单窗口站点数据上限 64 MiB，元数据上限 1 MiB；超限报错，不悄悄丢弃数据。

### 不能保证恢复的内容

恢复会重新加载网址，不是暂停整个系统。未提交表单、上传、网页 JavaScript 内存、支付/下单流程不能保证续接；不要用冻结保存正在提交的交易。只补存当前顶层页面的 sessionStorage，不遍历第三方 iframe。依赖该数据的窗口需要内核支持文档起始脚本，否则明确拒绝不安全恢复。

网站可以使 Cookie/登录令牌过期、撤销登录或要求二次验证；IP 变化、内核升级、风控也可能导致重新登录。不能承诺长期永不登录。卸载、清除应用数据或密钥失效后，冻结资料无法恢复。

## 基础抗指纹的范围

- 收敛 UA 中的 Android 机型与版本细节；支持时同步收敛 Client Hints，保留实际 WebView 主版本，不伪装为随机设备。
- 支持文档起始脚本的内核，在页面脚本运行前收敛 CPU 线程数、内存桶并屏蔽 WebGL 的未掩码厂商/渲染器查询。
- 拦截少量明确的追踪域名（使用完整域名/子域名边界匹配），拒绝第三方 Cookie，不提供相机、麦克风、定位或文件选择权限；证书错误不会放行。
- 禁止网页通过非 HTTP/HTTPS 导航直接唤起外部应用，不接入下载器。屏幕安全标志用于防截屏与网页预览。

这是基础减暴露措施，**不是完整硬件指纹伪装或网络匿名**。IP、登录账号、字体、Canvas/音频渲染、Worker 等仍可能被用于识别；页面级脚本可被检测或绕过。DNT/GPC 只是偏好信号，网站不一定遵从。此版本不随机化 Canvas，不内置代理或 Tor。

## 清理与验证边界

正常清除退出后由协调页面删除活动目录；冻结成功后也清除该明文目录。系统强杀或崩溃可能留下临时数据，在下次进入本工具、加载网页前清理或继续处理已经明确请求的冻结。解冻暂存归入统一管理目录，下次检查可清理中断残留。

编译、lint 和本地自检结果记录在 `evidence/browser-012-verification.md`。本机没有连接安卓设备，模拟器缺少硬件加速；本轮不将 JVM/脚本测试说成真机登录与页面兼容性验收。
