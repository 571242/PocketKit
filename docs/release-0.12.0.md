# 拾用 0.12.0：无痕浏览与加密冻结

入口：全部 → 网络工具 → 无痕浏览。

## 怎么用

- **新建会话**：点击「开始新无痕会话」打开独立浏览窗口。
- **浏览与搜索**：地址栏直接输入网址或搜索内容。
- **常用操作**：底部支持后退、前进、刷新、添加收藏。
- **冻结与退出**：直接退出立即清除所有浏览痕迹；点「冻结并退出」可保存当前登录状态与进度，下次点击即可解冻继续。

## 冻结保留什么

- **站点数据**：保留会话中的 Cookie、Local Storage 与 IndexedDB 等登录状态。
- **页面进度**：保留当前页面的标题、网址与阅读位置。
- **本地加密**：数据使用本机安全芯片生成的 AES 密钥加密保存，不上传、不备份。
- **独立管理**：随时可在列表点击解冻恢复，或长按删除不再需要的冻结副本。
