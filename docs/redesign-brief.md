# 拾用界面与功能整理：本次约定

## 用户确认
2026-10-13：0.1.6-startup 已可在用户手机使用。用户要求整体界面更美观简洁，文本只做简单功能介绍；未接通功能分析原因，免费可靠可修就修，否则移除。用户选择简洁现代工具箱，并明确理解一致；补充功能不应过于克制，安装包/空文件夹应可直接扫描所有系统授权可访问范围。

## 决策
- 原生 Java 界面，统一布局，柔和青绿点缀，跟随系统深浅色。保留搜索、分类、常用、最近与现有用户记录。
- 首页与页面不再显示开发验收、补强要求等长说明；工具介绍简短、真实。必要隐私、上传、删除和测量提醒保留并写短。
- 免费可靠实现优先，不接需申请密钥或付费服务；临时网络失败不等于不可实现。不能修的功能从真实目录移除，不只是隐藏灰色按钮。
- 安装包/空文件夹扫描可申请 Android 官方全文件访问授权；禁止root或绕过私有目录。保留SAF替代方式。不可读取的目录不能判为空；删除需确认，不自动批量删除。
- 不清用户数据，不卸载；保留0.1.6启动初始化顺序修复，用同包名/签名、更高版本号交付。

## 用户追加要求
用户实测AI图片识别、人脸融合、自动打码、OCR图片文字识别都报 `MlKitContext is already initialized`。这是重复初始化共因，优先修复统一惰性初始化，不将编译成功说成四项真机成功。用户明确删除垃圾分类查询与氢壁纸；每日60秒看世界接专门每日摘要来源，不能用少数RSS标题冒充。099无可靠成语分类数据且094词典已有原文词条，移除重复未接通入口；093/110/112按可靠公开来源及免费原则移除；106中文Wikimedia接口已实际HTTP200，实施修复。

## 本轮任务边界（覆盖旧module-contract的历史所有权）
- 界面：BaseToolActivity、MainActivity、AboutActivity、新增纯UI/简介辅助类及UI/启动顺序测试。
- 文案：LocalToolsActivity、MediaToolsActivity和core/local/media中的用户可见文案；不改业务逻辑或数据键。
- 审计：只读核对未接通项、扫描权限与device文案，证据确认后派实施。
- 调度者：决策记录、任务书、关键改动复审、整包构建、签名和交付验收；不编辑代理负责实现。

## 分层验收
子代理自行检查并提供关键路径、测试命令输出、网络来源。调度者核对改动与用户目标，检查扫描权限/取消/不可读目录/删除确认、入口真可用与数据保持，统一构建及lint，回归0.1.6启动顺序和APK签名/16KiB对齐，交付新APK。没有真实Android截图和设备测试时必须明确未实测，不把示意图当运行截图。
