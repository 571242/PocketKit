# 0.7.1-preview 返修说明

本次针对你反馈的三个问题逐项修改。**没有任何一项宣称已在你的手机上验证通过**——当前没有连接设备，真机验收仍未完成。

## 1. 管理器：给了权限仍显示"目录不可读取"

根因（已从源码确认，非猜测）：

- 默认目录曾落在应用私有目录，授权后不会自动换回共享存储，看起来就是"有权限却读不到"。
- "上级"可以在本地根目录继续往上爬，进入 `/data` 等无权限区域后必然失败。
- 读取失败一律报"请授权本地存储访问"，把"目录不存在""系统限制""权限未授予"混成一条错误。
- 从系统设置返回只依赖一个回调，缺席时不会恢复。

改动：授权后把私有目录自动迁回共享存储根；向上导航只沿真实父链；`onResume` 补恢复；错误按路径、权限状态、存储状态分因；Android/data、Android/obb 仍按系统限制如实说明，不假称可绕过。

自测：`ManagerPermissionSelfTest` 25 项通过（路径边界、权限分类、错误分因、SAF 混链拒绝）。

## 2. 开屏跳过：按通用规则重做

你提到"不止这两个应用"，因此改的是**通用匹配**，不是只给哔哩哔哩和网易云写死：

- 监听：开启控件 ID 上报与窗口变化事件，应用进入后台/前台都会触发。
- 匹配：短"跳过/Skip"文案（含"跳过广告""跳过 5s""5秒 | 跳过"）、边角区域、尺寸上限、进入应用后的时间窗；倒计时数字仅在顶部条带内接受。
- 保护：搜索、登录、设置、支付页面不匹配；钱包银行类应用整体排除；跨应用控件 ID 互不生效。
- 点击：先刷新节点再匹配，点击可点击节点或受限父节点；被拒绝时对重新确认的目标发中心手势（不使用固定坐标盲点）。
- 确认：返回成功只记为"已接受"，节点消失才记确认；每个前台访问最多 4 次尝试，冷却 650 ms。
- 诊断：功能页实时显示事件数、两款应用计数和阶段日志，可复制或导出，能看出卡在监听、匹配还是点击。

自测抓到并修掉三个真实缺陷：钱包类应用未拦截、跨包控件 ID 误命中、控件 ID 截取偏移 1 位（此条会让已知 ID 永不匹配）。`AdSkipRulesSelfTest` 74 项通过。

适配依据来自公开规则库中对目标应用可观察的控件标识（哔哩哔哩 `count_down` / `skip`、网易云排除设置与搜索页），仅作事实参考，未复制其代码或规则数据。

**仍需你验证**：两款应用当前版本的实际节点是否暴露、无障碍服务是否被系统限制。

## 3. AI 音色：真实模型推理

不再是 DSP 冒充。已落地：

- 模型：OpenVoice V2 的 ONNX 导出（`tone_extract.onnx` + `tone_color.onnx`，MIT，`Hinotsuba/OpenVoice-ONNX-v2` 固定版本 `74104c7`），全部离线运行。
- 引擎：`OpenVoiceConverter` 做 STFT、音色向量提取、8 段分块转换、可取消、原生资源释放；`OpenVoiceProcessor` 提供三音色并首次解压模型。
- 内置音色：清脆少女 / 清冷御姐 / 成熟男，三个 256 维音色向量随包内置。
- 自定义：保留用户自行添加音色文件的目录与接口，可换入自己的音色向量。
- 入口：V01 录音变声、V02 音频转换，引擎选"AI 音色"，音色列表随之切换为三种。

本机真实推理已验证：输入 8.63 秒 → 输出 8.63 秒，波形与输入不同，RMS 与峰值在正常语音范围，三个音色向量两两距离 9.8 / 11.2（确实不是同一个声音）。

**过程中排除的一个坑**：本机 SAPI 里 Kangkang/Yaoyao 实际回落成 Huihui，起初两个"不同音色"向量完全相同。已改用 WinRT 真正三个音色，并逐步核对哈希确认互不相同。
