# 拾用 PocketKit 0.10.2：代理通知图标修复

- 修复开启代理后，下拉通知仍使用 Android 系统同步图标的问题。
- 下拉通知新增当前应用的新版彩色图标；状态栏使用透明底单色工具箱图标，避免 Android 将彩色图标渲染成实心白块。
- 不修改代理连接逻辑、订阅、规则或用户数据。

## 安装

直接覆盖安装 `PocketKit-0.10.2.apk`，不要先卸载。versionCode 26，与 0.10.1 使用同一调试签名证书，不是生产发行证书。

## 热更新边界

已有服务器通道仅支持代理规则数据更新，不能替换 APK 内的 Java 代码和 Android 图标资源。本修复需要覆盖安装，未向服务器下发无效的资源更新。

## 验证

- 离线 `:app:assembleDebug :app:lintDebug` 通过。
- 新旧 APK 均通过签名验证，证书 SHA-256 一致。
- 没有连接 Android 真机或模拟器；不同 Android / 厂商系统的通知布局和实际显示效果尚未实机验证。
