# 尺子修复与定时自动抢票（0.2.2）

## 实际功能

抢票助手不再只有时钟。支持预约北京时间日期、时分秒，到点自动用安卓无障碍手势执行已录制位置：单点连点、多步骤顺序循环、可选只走一轮。点击间隔100至5000毫秒，尝试1至60秒，序列最多8步。多步骤优先按录制时捕获的完整按钮文字等待和定位，首步按坐标以适应开售按钮文字变化；识别文字可调整或清空。识别不到后续按钮时等待，仍在购买起始页时限时重试首点。

只针对绑定的目标App。切错App或锁屏时等待，不操作其它页面；屏幕方向/分辨率变化停止；预约错过整个尝试窗口不补点。手势串行派发，停止后旧回调不能启动下一步。超时或点击计划上限结束，并不宣称已抢到票。

读取到订单、支付或验证码提示时停止，留给用户核对/处理。识别依赖目标App提供可见无障碍文字，无法保证所有自绘页面都能正确识别。不能把“检测到页面”当成订单成立；不要录制支付位置，不录密码，未做支付自动化。不调用私有下单接口、不绕过验证码、不绕过锁屏。

## 使用

1. 在抢票助手中开启“自动点击权限”；在系统无障碍设置里启用“拾用 · 定时自动点击”。侧载APK如系统禁止启用，可能需要在应用信息菜单允许受限设置，须由用户自己确认。
2. 点击“录制购票点击步骤”，允许悬浮窗。切到已登录、准备好的购票App，在悬浮栏绑定当前App。
3. 加点时触摸一次购买按钮位置，触摸仅采点，不落到下层App。一个点就能连点。需要票档、人员、订单确认等后续动作，可自己导航至相应页面，继续采点并保存。
4. 返回助手，核对点位与识别文字，选择日期、时分秒、间隔和尝试时长，点击“预约自动抢票”。切回原购票页面并保持解锁，到点自动操作。
5. 可从悬浮窗、助手或可用的系统通知停止。建议先在无购买动作的页面测试，正式使用前提前选好演出、票档与人员。屏幕布局、字体缩放或页面结构变化后重新录制。

自动预约等待期间会保持亮屏，长时间等待耗电，建议开抢前几分钟准备。手动锁屏不会自动解锁或唤醒。仅倒计时模式只在临近目标时短暂保持亮屏，不执行点击。Android省电、服务被系统关闭、目标平台限制自动化或悬浮窗都可能使操作失败。

## 时间与结果边界

日期时间固定按Asia/Shanghai处理；支持09:37:30，过去时间拒绝，不自动挪到次日。成功网络参考以elapsedRealtime推进，失败保留原来源；不使用秒级HTTP Date冒充毫秒授时。来源与往返耗时明确显示，半程往返补偿仅是假设，不等于真实误差，也不是目标平台的专属时间源。自动任务运行/预约时不切换网络时钟。

这是一套可配置的UI自动操作工具，不是所有票务平台的专用接口适配器。页面速度、库存、排队、服务器时间及验证码决定最终结果，不能保证比别人快或一定抢到。显示的点击次数/任务结束不是购票成功。订单与金额必须在目标App里确认，支付由用户完成。个人使用也不代表平台不会限制自动化。

## 尺子修复

修复全屏对话框在DecorView尚未创建时调用WindowInsetsController的崩溃。顺序固定为setContentView、show、全屏布局与系统栏控制。页面离开/销毁时释放对话框。

保留已存校准值。银行卡参考改成全屏竖向两线校准，不将超宽框缩小冒充物理比例；明确保存，越界不允许保存，请竖屏校准。保存同步主页面滑块与预览。系统xdpi仅是估计值，屏幕显示边缘不等于外壳边缘，仍需实物校准。
