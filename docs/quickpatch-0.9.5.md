# 拾用 0.9.5：断开修复与精简

版本 0.9.5 / code 23。直接覆盖安装 [APK](../dist/PocketKit-0.9.5.apk)，不要先卸载；签名证书与 0.9.4 一致，沿用现有调试证书，不是生产发行证书。原订阅、录音、工具数据不清空。

## 这次改动

- 修复代理断开：主页面、快捷面板和通知栏统一发送显式停止指令；先关闭原生内核、Java/native TUN 句柄、统计和定时检查，再停止服务，不再依赖可能因系统绑定而延后的 onDestroy。连接中可取消，过期启动/失败回调不会重新连接。
- 读取节点池时过滤已删除订阅的孤儿节点和无凭据占位；保存时同步清理。可用手动节点和其他订阅保留，拉取失败仍保留原有有效节点。删除当前代理节点所属订阅时先停止代理，不静默连到其他节点。
- 主动删除「Hub 订阅」后，自动同步不再将它重新加回。若要恢复，可手动添加名称为「Hub 订阅」的订阅；云规则更新与这个开关独立。
- 应用启动图标使用本次提供的原图，包含常规、圆形和安全区适配的自适应图标。
- 首页声音工作台卡片移除。小功能中的录音、系统 TTS、DSP 变声和原快捷方式入口保留。
- 内置 AI 音色、模型与专用 ONNX 推理库不再打包。打开语音小功能时后台回收旧版解包的 `files/voice-ai` 模型目录，不删除录音/导出文件，也不跟随符号链接清理其他目录。
- VPN 关闭时不再在首页自动请求出口地址；更新/探测线程空闲后退出，服务停止会移除 VPN 内核和定时检查。未测量真机 RAM/PSS，不宣称具体内存降幅。
