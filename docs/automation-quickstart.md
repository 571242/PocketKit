# PocketKit 0.3.0 自动化工作台

发布状态：0.3.0/code11 调试签名安装包已生成，桌面构建、测试包构建、lint及算法/契约检查通过；没有连接Android设备，尚未验证真机运行。安装包与0.2.2使用同一证书，覆盖安装的数据保留仍须实机确认。

## 从哪里进入
在拾用首页搜索“自动化工作台”，或从“自动化”分类进入。抢票助手原入口仍在，也可把已有录制配方送到工作台继续编辑。

这是原生可视化模块，不是 AutoX.js 完整兼容层，也没有 JavaScript 编辑器。脚本是可预览、可修改的动作数据，导入不会自行运行。

## 第一次使用
1. 在系统设置开启本应用的无障碍服务，用于实际点击、滑动、文字节点操作。部分侧载安装需先在应用信息页允许受限设置，这一步由你在系统界面确认。
2. 授予悬浮窗权限，用于运行控制和目标采集；允许通知，保留随时停止入口。不要在没有控制入口的情况下运行自动任务。
3. Android 11及以上通过无障碍按需截图。Android 8–10的识图/OCR先点击屏幕捕获授权，保持投影会话；使用后停止投影。截图授权与无障碍是两项不同的系统能力。
4. 第一次先在无购买/扣款风险的普通页面测试。屏幕需要解锁；需要绑定目标应用的脚本，执行时把目标应用留在前台。

## 做一个连点脚本
选择连点模板，设循环次数和间隔，编辑点击动作的坐标，或使用屏幕取点。采集时先切到目标应用，再开始取点；采集触摸只用于选坐标，不会向目标应用透传一次点击。保存后点“启动此脚本”只建立准备浮条，尚不出手势；切到目标应用后点悬浮栏“开始”。运行中可暂停、恢复或急停。关闭控制会停止任务，急停不撤销已发生或已交给系统的一次手势。

循环次数为0表示一直循环直到你停止。需要无限重复时应保留合理的间隔，避免空循环占用CPU。运行总时限为0表示不设置总时长；预约等待不应占用正式执行的时限。

## 看到文字/图片再点击
- 文字：添加“等待文字出现”，输入要匹配的文字，选择本地OCR或无障碍节点来源，设置超时；后面接点击动作，并选择使用最近匹配位置。不是把目标文字写在动作的说明里。
- 图片：在目标页面框选并保存模板，或从图片文件选入；添加“等待图片出现”，选模板、阈值和超时；后面接使用匹配位置的点击。导出脚本会携带实际引用的模板，导入后不依赖原文件路径。
- 图片尽量选清楚且有区分度的小块；需要时限定识别区域。分辨率、主题、缩放和目标界面变化会影响识别，不保证同一模板适配所有屏幕。
- 如果识别未命中或超时，不应继续使用之前命中的旧坐标；先看日志，调整素材、区域或参数，不要盲目重试购买操作。

## 逻辑编排
条件步骤有命中分支与否则分支，循环步骤有子动作。可组合等待、点击/长按/滑动、输入、返回/主页/最近任务、识字提取、变量赋值与变量比较。识字结果可存到变量，再用于条件或后续输入；变量引用使用 ${变量名}，用于赋值、变量比较和后续输入文本。

输入文字之前，应先点击并聚焦目标输入框；引擎不会擅自选择页面里第一个输入框。点位以采集时真实屏幕像素为参考，同方向执行可缩放；换方向采集请新建脚本。

脚本的目标包名可留空，通用引擎不按用途设置黑名单，也不内置不可关闭的付款或验证码停机词表。实际操作由使用者决定；系统授权、锁屏与安全窗口等平台限制不会被绕过。

## 抢票助手怎样复用
已有日期、时分秒、校准时钟与录制配方保留。抢票预约会生成通用脚本：等待到开始时刻、按配方查找文字或点击点位、按间隔继续或循环；停止和日志来自同一执行核心。需要复杂识图/识字判断时，送到工作台编辑，而不是再维护一套专用执行逻辑。

不承诺抢到票，不验证实际购票/支付成功率。平台规则与自动化造成的实际后果需要你自行判断。

## 保存与交换
可以保存、复制、重命名和删除脚本，通过系统文件选择器导入/导出。导入新建脚本，不覆盖旧脚本，也不自动开始。建议先预览每一步，再授权运行。未填写完文字、变量或图片模板的步骤可作为草稿保存，但不允许直接执行。导入/导出包最大16MiB，单个图片素材最大8MiB且限制解码像素；过大时会明确拒绝，而不是生成打不开的文件。截图/模板保存在应用私有目录，本模块不接云端识别服务，不主动上传屏幕图片。导出包包含文本参数和所引用的图片，分享前检查其中的敏感信息。

## 已知验证边界
当前桌面没有连接 Android 设备，不能把编译/JVM算法通过称为实际手机运行通过。真机无障碍授权、悬浮窗触摸、系统截图、ML Kit OCR推理、旧数据覆盖安装与特定目标应用的行为仍需按验收清单测试。

模型沿用项目已有的闭源 ML Kit 打包中英文模型，识别设计为本机运行；没有做网络监听审计，不宣称第三方SDK已被证明完全零诊断通信。安全窗口可能拒绝截图或显示黑画面，会导致无法识别。
