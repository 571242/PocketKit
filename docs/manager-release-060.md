# 拾用 0.6.0：文件管理器测试版

本版独立实现用户选定的 Level 1，不复制 MT 商业代码、资源或本地库。此前的 APK 检查仅确认包结构、Manifest 和菜单资源，不构成完整逆向或运行验证。此次未实现 Level 2–4。

## 使用入口

首页按“常用 / 全部 / 管理器”排列，保留连点器。“常用”默认打开，置顶在上，最近使用在下；已置顶条目不会在最近区重复。长按工具切换置顶。

“管理器”打开独立双窗口；“全部”的文件与管理器分类新增管理器、ZIP/APK 浏览提取、应用提取、文本对比、Hex、文件哈希六个入口。

## 双窗口管理

每个窗口都有“位置”和“上级”。点击路径切换当前操作窗口，筛选框仅筛选当前目录的名称。短按目录进入，短按文件选择查看/对比/校验/其他打开方式；长按条目进入多选，再点其他条目增减选择。

底部操作栏可横向滑动，支持复制到另一窗、移动到另一窗、全选/取消、所选操作、删除、新建、刷新、工具。文件夹重命名和属性通过长按选择一个条目后点“所选操作”。底部复制/移动以当前窗口为源、另一窗当前目录为目标。

本地文件、云端文件与 Termux 文档统一使用这些操作。新建和复制同名时保留两份；重命名遇到同名时拒绝。删除需要确认，无回收站。操作中退出需确认；跨来源移动时请勿在其他应用并发编辑源目录。

同一来源优先调用本地/提供器原生移动。跨来源移动先复制、核对内容哈希及目录结构，再删除源；失败时已完成条目会保留，不承诺跨云服务原子事务。符号链接不递归复制，防止循环和越界。只读提供器会拒绝写操作，不会伪装成功。

## 云盘与 Termux（重要）

1. 安装、登录支持 Android Storage Access Framework / DocumentsProvider 的云盘应用，或安装提供文档接口的 Termux 版本。
2. 在所需窗口点“位置 → 添加云盘 / Termux / 文档目录”。
3. 在系统文件选择器侧栏选择云盘或 Termux，进入目录并点“使用此文件夹”。请勿选择其他应用的私有目录来尝试绕过权限。
4. 授权位置自动加入收藏；可与另一窗口本地文件互相复制、移动、创建、重命名、删除，也可使用查看/对比/哈希。
5. 在“位置 → 已收藏的位置”再次打开；长按收藏移除记录。移除收藏不等于撤销系统授权，可在系统应用设置清除授权/数据。

云服务认证、网络传输、实际目录能力由提供器负责，拾用不保存云盘密码。云端目录仍在加载时会提示刷新，授权撤销、断网或只读会显示错误。只支持单文件的提供器可用“打开单个文件”，不能假装支持目录树。

**0.10.0 起内置 SFTP、SMB、FTP/FTPS、WebDAV 四种协议的远程浏览器**，入口是「位置 → 远程连接」，与本地双窗互不影响。它仍不是完整复制 MT 的网络存储模块：只支持密码登录（无密钥文件）、WebDAV 只支持 Basic 认证、SFTP 不校验主机指纹、FTP 只能用被动模式。以下关于文档提供器的说明仍适用于云盘与 Termux。 没有提供 Android 文档接口的服务，需要额外兼容的文档提供器才可纳入统一管理。Termux 的来源是否出现在侧栏由其安装版本和系统决定；本次无真机，未验证特定云盘/Termux 版本的端到端兼容性。

本地共享存储可以申请“所有文件访问”；也可以只用系统目录授权。Android 仍限制 Android/data、Android/obb 及其他应用私有目录；本版不含 Root/Shizuku 绕过方案。在 Android 8/9 或缺少目录关系查询能力的提供器上，应从同一个授权根目录进入左右窗口，不能安全核对的独立根之间的目录递归操作会拒绝。

## 系统打开与分享

在其他应用的“打开方式”选择“拾用管理器”，可以查看文本、Hex、哈希、浏览 ZIP/APK 或复制到另一窗口。也支持分享单个或多个文件；在管理器“工具 → 导入外部收到的文件”复制到当前窗口，不自动改动源文件。

发送方必须授予 URI 读取权限；只有单文件授权时不会自动获得父目录权限。某些应用强制用内置预览器，不调用系统 chooser，拾用无法强行出现在它的菜单中，可改用系统分享入口。

管理器里的“其他应用打开”会创建只读临时副本，并通过受限内容提供器授予读取权。不会暴露整个私有目录，也不会把其他应用编辑副本的结果自动回写源文件。

## Level 1 功能与边界

- 双窗口：目录浏览、多选、复制、移动、删除、重命名、新建、属性、筛选、收藏及恢复位置。
- ZIP/APK：以目录树浏览并按需复制提取到另一窗；支持标准未加密 ZIP/APK，不支持 RAR/7z、加密 ZIP、压缩包内写回/重签名。可用全选后复制来提取整个当前目录。CRC/长度错误、不安全路径、重复路径会拒绝。
- 应用导出：枚举已安装应用，搜索后导出 base.apk、所有 split APK、图标 PNG、包名与版本 JSON 到当前窗口的新文件夹。拆分包导出不是合并成单 APK；本版不安装拆分包，不导出私有用户数据。
- 文本差异：UTF-8 文本逐行比较，增删高亮，保留 CRLF/末尾换行差异；每份最多 256 KiB 和 1600 行。其他编码会明确拒绝，避免乱码比较。
- Hex：每页 4096 字节，支持十进制字节偏移跳转；不是二进制编辑器。
- 哈希：流式计算完整文件的 MD5、SHA-1、SHA-256。MD5/SHA-1 仅作兼容校验，不用于安全签名。

ZIP/APK 下载缓存和对外打开副本单次最多 512 MiB；压缩成员读取/一次递归提取最多 512 MiB（多个独立批次分别计限）。管理器临时缓存总量限 1 GiB。可用“工具 → 清理临时缓存”释放；会关闭 ZIP 浏览并使分享副本失效，不删除原件。目录列表最多 50000 项，递归深度 128，压缩包最多 100000 条目；超限拒绝而非静默截断。

## 安装与验证

安装 dist/PocketKit-0.6.0.apk，版本号 0.6.0，versionCode 14，仍为本机调试签名。请优先覆盖安装，先导出重要账本与自动化配置，勿为解决签名冲突直接卸载旧版。

具体离线检查结果见 ../evidence/manager-060-verification.md。没有连接真机，不能以编译、反射、算法或包结构测试代替 UI 与提供器的实际验收。

建议先用一次性测试目录验证：本地左右复制/移动，Termux 与本地互传，云盘断网/只读错误，文件夹重命名，系统打开方式，压缩包提取，以及退出/旋转后的目录恢复。确认后再操作重要文件。
