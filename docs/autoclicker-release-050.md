# 拾用 0.5.0：连点器操作改进

## 安装

使用 [新版 APK](../dist/PocketKit-0.5.0.apk) 覆盖安装，**不要先卸载**。包名仍为 `cn.xianhua.pocketkit`，版本号提升至 13；签名一致性与实际检查结果见 [验证记录](../evidence/autoclicker-050/verification.json)。卸载会丢失应用私有脚本及其他工具的数据；重要脚本请先导出。本包仍使用开发调试签名，不是商店发行版。

## 变化与使用

- **首页入口**：底部原“说明”按钮改为“连点器”，与“全部 / 常用 / 最近”同排，删除此前独占一整行的模块。
- **整份脚本重复**：打开脚本编辑器，名称下方直接设置“只执行一次 / 指定次数 / 直到手动停止”和轮次间隔。每轮从第一个顶层动作重新开始；旧脚本默认只执行一次。内部已有“直到停止”的循环动作时，这个动作不结束，整份脚本就不会进入下一轮。
- **贴边收起**：播放悬浮控制支持收起为贴边小窗；点小窗展开控制，长按急停。收起不停止脚本。音量下键和通知栏的停止入口仍保留。
- **识别后直接点击**：在“等待文字 / 等待图片 / 如果文字 / 如果图片”里勾选“识别到后直接点击目标”。命中后点击本次匹配框的中心，不必再手填坐标；“如果”动作点击后再执行命中分支。没找到不会点击旧位置。
- **分层编辑**：“如果图片 / 如果文字”展开后，分别在“识别到”和“未识别到”区域添加后续动作；各区有动作数量和摘要。“等待”动作则等待命中，再执行后面的普通动作。添加动作按常用和类别选择，保留原有全部动作类型。
- **移除翻译**：联网和本地翻译入口、实现及专用 ML Kit 翻译依赖移除；OCR 和其他工具保留。

## 建议的快速验收

1. 覆盖安装后打开首页底部“连点器”，确认与其他导航同排。
2. 在无风险页面新建“点击 → 等待”的脚本，设置整体重复 3 次，先保存再重开检查设置。启动后确认整份动作清单执行 3 轮。
3. 运行时测试收起、拖到屏幕边缘、点开暂停、继续和停止；再测试长按小窗与音量下键急停。不要在支付、购买或转账页面测试。
4. 添加“如果文字”或“如果图片”，设置条件，勾选直接点击，在命中和未命中区分别添加不同动作，检查实际分支和点击位置。文字容易重名时选择“完全相同”并框选识别区域。
5. 导出再导入脚本，核对整体重复、直接点击开关与分支动作；已有旧脚本应仍是单次执行。

## 已完成的离线验证

整包 `assembleDebug`、`lintDebug`、`testDebugUnitTest`、`assembleDebugAndroidTest` 构建通过；显式执行并通过核心执行器、录制会话、脚本编解码、两组原有 UI 接线检查、新编辑流程检查、模板匹配及悬浮窗几何自测。编译后目录反射检查为 91 个入口全部支持。UI 接线检查只读源码，几何检查只验证整数运算；不是渲染、触摸或真机测试。Lint 无错误，仍有工程警告。

## 边界

- 变量在轮次之间保留，与已有循环动作一致；最近识别位置每轮清空。启动延迟仅在整份脚本开始前等待一次，总时限覆盖全部轮次。
- 识图、OCR、截图、手势回执和系统调度都会耗时；设置的间隔不是精密计时保证。文字或图片识别错误也可能导致错误点击，应先在无风险页面验收。
- 绑定应用、锁屏、方向变化及无障碍权限检查仍生效，不绕过安全窗口或系统授权。参考分辨率和页面布局改变时，需要重新核对取点和模板。
- 急停阻止后续动作，无法撤回 Android 已接收的当前手势。厂商后台限制、省电和服务强杀仍可能中断运行。
- **本轮没有连接安卓设备，尚未验证手机上的实际显示、触摸落点、厂商权限与长时间稳定性。** 离线执行器自测、源码 UI 接线检查、编译和 Lint 不等同于真机验收。最终已执行的检查以验证记录为准；未运行 connected instrumentation、Release/R8 或商店验收。

此前录制、真实取点与屏幕采集的固有限制仍见 [上一版说明](autoclicker-release-040.md)。
