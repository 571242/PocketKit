# 拾用 PocketKit 0.11.0

版本号：0.11.0（versionCode 29）
系统要求：Android 8.0（API 26）及以上，支持 arm64-v8a、armeabi-v7a。

直接覆盖安装即可，保留原有签名和应用数据。

## 新增功能与用法

- **轻量阅读器**：支持 Markdown、TXT/代码、HTML、EPUB、PDF、DOCX/XLSX/PPTX。支持目录跳转、内容搜索、字体缩放和断点记忆。PDF 逐页渲染并支持放大查看，Office 提取正文和表格进行文本级排版。
- **贴屏参考图**：选择本地图片或从其他应用分享过来，以悬浮窗形态固定在屏幕上。支持自由拖拽、捏合缩放、透明度调节和点击折叠。
- **浏览器局域网互传**：同一局域网下启动后，电脑通过浏览器直接打开对应地址（支持扫码），即可双向收发文件与剪贴板文字。无需安装任何第三方客户端。
- **重复文件清理**：按内容 SHA-256 识别重复文件，删除前自动重算并校验保留文件与待删文件的真实内容，避免误删。
- **批量重命名**：支持替换、前后缀、自增编号并提供完整修改预览，遇到重名或异常字符会自动拦截。
- **压缩与解压**：可创建标准 ZIP 及 AES 加密 ZIP；解压支持常见的 ZIP、7z、RAR、tar 格式。解压统一在独立子目录展开，不覆盖已有文件。

## 细节优化

- **文件管理器**：各格式文件可直接调用对应的新工具处理；菜单新增批量重命名与快速分享入口。
- **快捷入口**：首页长按/点击工具菜单可置顶常用工具或直接生成系统桌面快捷方式。
- **计时与提醒**：倒计时与番茄钟改用系统闹钟调度和本地持久化，锁屏或应用切到后台后到点依然能正常响铃提醒。
- **SFTP 连接**：首次连接增加服务器主机指纹核对，指纹变更时主动阻断连接。

## 使用注意事项

- 离线阅读器定位为轻量查看工具，不支持老旧 Office 专有二进制格式（如 .doc/.xls）及带 DRM 加密的电子书。
- 局域网互传采用局域网 HTTP 明文传输，请在可信任的家庭或办公 Wi-Fi 环境中使用。
- 当前版本基于开发环境与算法回归验证，未在各品牌特定系统的后台查杀策略上做真机测试。
