# 拾用 PocketKit 0.10.3：统一通知应用标识

修正 0.10.2 只在通知右侧添加新版大图标、没有解决左侧旧应用标识的问题：

- 应用图标和 VPN 服务图标统一使用新的 `ic_pocketkit` 自适应资源入口。
- 移除旧青绿向量图，旧 `drawable/ic_launcher` 资源名改为指向新版图标的别名。
- 删除右侧重复的大图标；状态栏保留透明底单色工具箱小图标。
- 不改规则、订阅、代理连接逻辑或用户数据。

## 更新与安装

只保留现有 GitHub 仓库更新通道，不新增入口、不切换回服务器 APK 更新。服务器仅存档安装包。

直接覆盖安装 `PocketKit-0.10.3.apk`，不要卸载。versionCode 27，沿用同一调试签名证书，不是生产发行签名。

## 验证与边界

离线 assembleDebug 与 lintDebug 通过。检查最终 APK 的应用/服务图标引用、旧资源别名和签名。

没有连接真机，无法保证厂商通知中心立即清除已缓存的旧图标。覆盖安装后先重新开启代理；若左侧仍为旧图标，可重启手机刷新系统图标缓存，无需卸载或清除应用数据。实机问题在用户确认之前不标记为已验收。
