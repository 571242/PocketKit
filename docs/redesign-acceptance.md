# 本轮验收清单

## 入口和数据
保留包名、签名、用户存储键及版本升级路径；启动控制器依然在内容视图创建后调用。目录条目依据实际编译supports核验，不再用固定96的历史数量判定成功；源码归档排除私钥/缓存。

## 界面和文案
首页只呈现名称、一句话作用、分类与搜索/常用/最近；没有未接通、补强要求或待验收类开发正文。工具页统一输入、选项、主操作和结果，中文大字体可用。上传/公开链接/数据删除等确认不可因减字消失。深浅色/IME/系统栏规则保持。未接设备时不声称有真实手机视觉验收。

## 功能
逐项记录未接通功能的可修证据或移除理由。网络暂时失败与不可实现分开。删除入口同步目录数据及编译合同，不能仅隐藏灰色按钮；不能伪造接口成功或回退到泛搜索页冒充实现。

## 扫描
Android官方透明授权、回跳检查与SAF替代；取消/离开页面停止后台扫描；重复扫描不混旧结果。系统禁止读取或目录遍历失败不计为空；扫描根不删、符号链接不越界、删除前重验空、不递归误删。有效APK及真实结果列表/计数验证；Android私有区域不承诺扫描。

## 本次实测问题及每日摘要
MLKit覆盖首次使用、重复打开、跨翻译/图片工具、并发初始化；只修共因，不吞初始化异常或假称功能真机通过。确认氢壁纸与垃圾分类从目录/支持分发移除；099不使用四字筛选冒充成语分类。每日摘要用经过实际验证的专门来源，真实日期/要点/来源清楚；过期或未来数据不能冒充今日。106使用已真实返回events/text/pages.lang=zh的官方接口并测试解析和失败路径。
