- 锐化、插值、线性几何恢复、人脸对齐混合、分离轮廓计数为经典/规则算法；不是生成式换脸、神经超分或任意场景目标检测。
- 新闻速读使用公开RSS标题/来源/日期，不是原版每日60秒编辑稿；规则对联不等于专业创作。

- OCR模型随包，翻译模型需按需下载，闭源ML Kit可能产生诊断通信；系统TTS可能联网。
- 上传图床/图搜/搜番须逐次确认，第三方保存与公开链接无法由本应用保证删除。
- 账本禁用系统备份；卸载会丢失本机记录，先自行导出。
- FTP为页面内临时明文局域网分享，切出即停，不是后台服务。
