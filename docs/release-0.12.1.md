# 拾用 0.12.1：无痕浏览界面重做

入口：全部 → 网络工具 → 无痕浏览。

## 怎么用

- **新建会话**：点「开始新无痕会话」打开独立浏览窗口。
- **地址栏**：一条细顶栏，输入网址或搜索内容，回车即走；平时只显示域名。
- **标签页**：顶栏右侧数字是标签数，点开可切换、关闭、新建，最多 8 个。
- **菜单**：顶栏 ⋮ 里有刷新、收藏、收藏夹、关闭当前标签页、冻结并退出、退出。
- **冻结与退出**：直接退出立即清除所有浏览痕迹；点「冻结并退出」可保存当前登录状态与进度，下次点击即可解冻继续。

## 冻结保留什么

- **站点数据**：保留会话中的 Cookie、Local Storage 与 IndexedDB 等登录状态。
- **页面进度**：保留当前页面的标题、网址与阅读位置。
- **标签页**：多标签会话一起冻结，解冻后标签页都在。
- **本地加密**：数据使用本机安全芯片生成的 AES 密钥加密保存，不上传、不备份。
