# 拾用 0.13.0：修改定位与模拟足迹

入口：全部 → 设备测量 → 修改定位 / 模拟足迹。

两个功能共用同一个地图选点页，区别只是一次给你一个点还是一条路线：

- **修改定位（L01）**：在地图上点一个位置，或者搜一个地名，启动后系统定位就停在那一带，并带一点随机抖动，看起来不像死钉在坐标上。
- **模拟足迹（L02）**：在地图上依次点出几个途经点，连成一条折线。启动后按设定速度沿路线匀速前进，到终点停下。适合记录散步、跑步路线，或让位置"从 A 走到 B"。

## 前置条件（很重要）

1. 打开系统「开发者选项」：设置 → 关于手机 → 连点「版本号」7 次。
2. 进入「开发者选项 → 选择模拟位置信息应用」，选中**拾用**。
3. 确保系统定位总开关是开着的。

少了任何一步，页面顶部会有一条黄色提示，点提示里的按钮可以跳到对应设置页。没把拾用选为模拟位置应用时，「启动模拟」按钮是灰的。

## 怎么用

- **选点**：直接在地图上点，或在上方搜索框输地名（走 OpenStreetMap 的 Photon 服务，不需要 key）。足迹模式可以连续点多个点，点错了在底部点「×」删掉。
- **调速度**：足迹模式下 0.3–8 米/秒。1.4 m/s 大约是正常步速。
- **调抖动**：0–12 米，默认 2 米。设为 0 就是精确停在坐标上。
- **启动**：点「启动模拟」。之后可以退出这个页面去别的应用看效果，位置会继续更新。
- **暂停 / 继续**：只有足迹模式有。页面底部或通知栏里都能操作。
- **2 倍速**：只有足迹模式有。赶时间时用，路线走完会停在终点。
- **停止**：页面底部或通知栏里的「停止」。

## 它做了什么、没做什么

- 用的是 Android 系统自带的**测试位置提供器**（`addTestProvider`），把 `gps`、`network`，Android 12 及以上再加 `fused` 三个 provider 换成模拟值。没有引入任何第三方地图 SDK，也没有申请真实定位权限。
- 底图是高德的公开栅格瓦片（GCJ-02），搜索走 Photon（WGS-84）。页面里的坐标统一按 GCJ-02 显示，写进系统前会转成 WGS-84，避免地图上的点和实际注入的点差出几百米。
- 系统会把这些位置标记为 mock。银行、考勤、打车、部分游戏会直接检测并拒绝，这不是 bug，是系统行为。
- 停止后测试 provider 会被立刻注销，真实定位马上升效。如果进程被系统强杀，下一次打开这个页面会自动清理残留的测试 provider。

## 已知边界

- **尚未真机验收**。这一版只做了编译、lint 和坐标系/路线几何的纯 JVM 断言（48 条），没有在真机上点过。模拟位置这一段涉及系统 app op、厂商 ROM 差异，真机行为可能和这里写的不完全一致，第一次用请先试一个无关紧要的应用。
- 部分厂商 ROM（尤其国内定制系统）会对 `addTestProvider` 加额外限制，或者不允许替换 `fused`。代码对单个 provider 失败做了容错，只要 `gps`/`network` 有一个成功就继续跑。
- 页面用的是系统 WebView，需要 Android System WebView 正常（绝大多数机器都有）。地图瓦片和地点搜索都要联网，离线时只能盲点地图。
- 坐标系转换用的是公开的 GCJ-02 算法，和各家地图的实测偏差通常在几米内，不保证和某个具体应用的判定完全一致。

## 隐私

- 选点和路线只存在内存里，退出页面就没了，不写文件、不上传。
- 地图瓦片请求会暴露大致的地图范围给高德；地点搜索的关键词会发给 Photon（`photon.komoot.io`）。除此之外不发送任何设备信息。
