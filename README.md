# 拾用 PocketKit

个人安卓工具箱。

仓库：<https://github.com/571242/PocketKit>。更新检查也在应用内「全部 → 右上角 ⋯」里，仓库地址可以改。

## 日常工具与体验优化 0.11.0

这一版把常用的几个日常工具补齐了，覆盖安装即可：[当前 APK](dist/PocketKit-0.11.0.apk)。

- **轻量阅读器**：读 Markdown、纯文本、代码、离线网页、EPUB、PDF 及 Office 文档（docx/xlsx/pptx 预览）。
- **截图贴屏 / 参考图**：选图或直接分享图片后悬浮贴在屏幕上，支持拖动、缩放、透明度调节和折叠收起。
- **局域网互传**：手机启动后用电脑或其他设备扫码/打开网页直接收发文件与文字，不走外网。
- **文件去重与批量改名**：重复文件按内容特征查找并二次复核，支持批量改名带实时预览。
- **压缩解压**：支持标准/加密 ZIP 打包，解压支持常见 ZIP、7z、RAR 和 tar 格式。
- **体验与细节**：管理器与各工具打通；首页工具支持置顶与桌面快捷方式；计时器和番茄钟改为系统级闹钟与断电/重启持久化；SFTP 补齐了主机指纹校验。

详细限制与说明见 [0.11.0 说明](docs/release-0.11.0.md)。

## 远程连接与更新源

管理器新增自己实现的远程文件连接，入口在「位置 → 远程连接」，和本地双窗是两个独立界面：

- **SFTP**（jsch）：密码登录。0.11.0 起首次连接需确认主机指纹，已保存指纹不一致时拒绝连接；只接受客户端密钥认证的服务器仍会明确报错。
- **SMB2/3**（smbj）：填主机、共享名和账号，目录用反斜杠。
- **FTP / FTPS**：手写实现，优先 MLSD 列目录、EPSV 建数据连接，不支持主动模式。
- **WebDAV**：手写实现，PROPFIND 列目录、PUT 上传、MOVE 改名，只支持 Basic 认证。

能浏览、上传、下载、重命名、新建文件夹、删除。密码用 AndroidKeyStore 里的不可导出密钥做 AES/GCM 封装后落盘，没有明文备份；密钥库不可用时直接拒绝保存，不降级成明文。下载统一落到应用缓存目录（完整路径显示在状态行），不往用户的文件夹里乱写。

更新入口收敛成一个按钮：只在「全部」页右上角出现，点开是免责声明、当前版本、可改的仓库地址；检查更新只读 GitHub Releases，然后跳到发布页或 APK 直链，不再走原来的 APK 更新通道。免费 VPS 网速差，下载交给浏览器或别的下载器。

管理器不再霸占所有应用的「打开方式」：删掉 `ACTION_VIEW` 的 `*/*` 过滤，改为接收分享 + 菜单里的「打开所在位置」。只被授予单个文件时，会跳到最近的可读上级目录，并说明没有精确定位到文件本身。

这一版还修了一批静默出错的地方：视频压缩里编码器输出格式的注册时机与 muxer 轨道、位图没在 finally 回收、中文数字负数输出「负负」、单位换算里「顷」差一倍、括号嵌套过深触发 StackOverflow、文本拆分遇到 `[` 抛异常、纪念日把一次性日期判成每年重复、代理规则产物每版残留十几 MB 等。

历史包可查看 [0.10.1 APK](dist/PocketKit-0.10.1.apk)；明细见 [更新说明](docs/quickpatch-0.10.1.md)。四种协议尚未在真机与外部生产服务器跑过，仅通过静态契约与本地传输逻辑测试。

## 构建

环境：JDK17、Gradle8.14.3、Android SDK platform36/build-tools36.0.0，AGP8.13.0；minSdk26，targetSdk36，Java17，无Kotlin/Compose。

设置 JAVA_HOME 与 ANDROID_HOME，然后在项目根目录执行 `gradle --console=plain :app:assembleDebug :app:lintDebug`。本项目不附全局SDK、Gradle缓存或签名私钥；首次构建须联网获取公开依赖。无Gradle wrapper，可使用本机既有Gradle8.14.3。

**构建前需要自备代理核心**：`app/libs/libbox-1.14.3.aar`（sing-box 的 Android 库，112 MB）没有放进仓库——它超过 GitHub 的 100 MB 单文件上限，Git LFS 在这个账户上也被服务端拒绝。可从 [Releases](https://github.com/571242/PocketKit/releases) 下载同名附件，放到 `app/libs/` 下再构建。不需要代理功能的话，从 `app/build.gradle` 的 `dependencies` 里删掉那一行即可，其余模块能正常编译。

本机工具链见 docs/build-environment.md。Debug APK使用本机Android默认调试证书，不是生产发布签名；无需也不应向助手提供私钥、口令或服务密钥。

## 文件、记录与联网

- 可以使用系统文档选择器授权指定文件/目录；管理器浏览全部共享存储可选申请“所有文件访问”，不授予其他应用私有目录访问权。应用导出在本机枚举安装包，不上传应用清单。EXIF清除、图像/PDF处理默认输出新文件。
- 账本和记录保存在应用私有存储；系统备份关闭，卸载会丢失，请手动导出。
- OCR模型随包；翻译功能已移除，不再下载翻译模型。其余 ML Kit 功能仍使用闭源SDK，可能有诊断/使用等通信，不是零通信组件。
- 上传图床、图搜、搜番必须逐次选择并确认第三方服务。图床公开链接可能长期保留，本应用无法代删第三方保存内容。
- FTP为页面内临时分享：导入是复制，不移动原文件；同名导入去重。关闭/切出页面即停止；使用随机会话凭据，被动模式，仅可信局域网，协议本身不加密。
- 噪音默认dBFS，不冒充声压级；尺子/水平仪要校准。QQ只是正规跳转，不绕过权限、不读取聊天、不代发消息。
